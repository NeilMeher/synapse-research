# ARTHA learning guide

Open the [ARTHA workbench](../artha.html#shock), set a 2024 domestic construction purchase to $100 million, then compare the gross output, value added and imported input totals. Change to ten broad groups and keep the same purchase. The demand industry remains construction, but the supplier structure is grouped.

At [the coefficient inspector](../artha.html#flows), select a purchasing industry. A column records how much each domestic supplier sells per dollar of buyer output. Imported inputs have a separate coefficient. Try the same column after changing vintages. A difference can reflect both price and production changes.

Use the [Academy exercise](../academy.html#input-output) to reconstruct two rounds without national data. The [archived table](../artha.html#evidence) gives the registered year, resolution and equal-shock comparisons. The [source note](../research/artha-sources.md) shows why the ADB workbook was selected and which alternative data was unavailable.
