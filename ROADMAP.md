# Roadmap

| Milestone | Delivery and dependency |
|---|---|
| 0 · Discovery | Portfolio audit, primary literature, novelty comparison, protocol, threat model and budget. |
| 1 · Shared infrastructure | Seed policy, validated contracts, experiment runner, reference tests and static site. Depends on 0. |
| 2 · ECHO | Communication and correlated evidence experiment, archived run, interactive replay and manuscript. Depends on 1. |
| 3 · MIRAGE / REFLEX | Calibration benchmark and reconciled market simulation. Depends on ECHO shared contracts. |
| 4 · MORPHEUS / ALPHA DECAY | Memory interventions and endogenous strategy crowding. Depends on the shared agent and market contracts. |
| 5 · NOESIS / SCIENTIA | Symbolic discovery and scientific workflow validation. Depends on provenance and controlled holdouts. |
| 6 · AXIOM / GAME OF CIVILIZATIONS | Incentives, institutional mechanisms and resource exchanges. Depends on agent and network models. |
| 7 · ARTHA / ENERGIA | Verified public economic data, engineering constraints and infrastructure finance. Depends on reconciled flows and source versions. |
| 8 · CHRONOS | Historical evidence and identified causal designs. Depends on explicit evidence classes and assumptions. |
| 9 · Integration | Cross-lab experiments, manuscripts, review, education and public release. |

Release status follows mathematical, experimental, statistical, software, website, documentation and recorded review gates. Later milestones are proposed.

Phase II begins with ECHO 2.0 matched-moment dependence, a rational reference and distributional bounds. The next vertical slices are MIRAGE matched confidence, REFLEX deterministic market accounting, and CONVERGENCE. Each requires its own frozen design and computed evidence.
