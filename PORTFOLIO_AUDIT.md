# Portfolio audit

Read-only audit of the public NeilMeher portfolio. GitHub authenticated the account and returned the repository inventory. The table covers all 23 charter-named repositories and the additional SLINGSHOTNEWS2 snapshot. Commit links are pinned to shallow clone HEAD. The profile repository is outside the research inventory. No portfolio code was incorporated.

The files listed were consulted at source, declaration, fixture or protocol level. Test files and CI presence record available coverage. A passed test is local evidence only where explicitly indicated. Upstream CI run status, data licenses, empirical validation and independent review remain unverified unless otherwise stated. Current source availability was checked, but upstream claims and every original external data cell were not independently reproduced. For each of four selected stdlib repositories, ran `python -B -m unittest -v` in the shallow clone. All 13 selected tests passed.
