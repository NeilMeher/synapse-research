# MIRAGE empirical pilot protocol

**Study mirage-empirical-pilot-001 · Exploratory actual-model evaluation · v1.0.0**
Research question: for SmolLM2-135M-Instruct Q4_K_M on four generated task families, how does a plausible incorrect advisory cue affect the Brier score of a self-reported probability that the selected option is correct? The directional expectation is a higher Brier loss under the cue. The pilot measures expressed behaviour under a fixed prompt.

## Sampling and exposure

There are 64 pilot items, 16 each on arithmetic change, conditional probability, missing-mean components and order inference. Both neutral and incorrect-advice prompts use the same question and choices. The added sentence identifies one plausible wrong option as another solver's suggestion without indicating whether it is correct. Correct and cue option positions are both balanced within each family. The cue target has a fixed family-specific offset among positions, so associations tied to particular distractor types and cue positions cannot be identified. Each family has eight neutral-first and eight cue-first pairs. Each completion starts afresh, with local prompt caching and context shifts disabled, and tools absent. Task metadata, key and scores are excluded from the model-facing two-message request. Exactly one generation per condition per task will be attempted. The correct-cue and irrelevant-cue arms are deferred under this pilot budget.

The development split has eight items and up to 16 requests per prompt version, 32 requests across both versions. The unconstrained development attempt produced zero valid answer-confidence pairs. Before opening the pilot split, the prompt was simplified and a llama.cpp output grammar imposed the two-line format. The grammar allows A through D, ABSTAIN, and every integer percentage from 0 to 100. This evaluates expressed confidence under constrained formatting. Spontaneous format compliance lies outside this design. Its outputs stay outside the pilot. Eight separate calibration items are frozen as a distinct template family for future method development and receive no inference in this study. A confirmatory or replication split remains ungenerated until its own design is fixed. Variants within a family share structure. Newly generated numbers do not establish absence of training contamination. Frozen files and machine configuration are in [the study configuration](../empirical/mirage-pilot-v1.json) and the `empirical/datasets` directory.

## Model and budget

Expected model is HuggingFaceTB/SmolLM2-135M-Instruct as bartowski revision `09816acd5d99df7be770d85ea30822623dab342c`, Q4_K_M, using the model-supplied chat template and llama.cpp b12823 on Windows CPU. The machine configuration pins model weight, runtime archive, executable and inference settings. Local inference uses 512 context tokens, up to 32 new tokens, two CPU threads, one slot, no GPU, greedy temperature 0 and requested seed 71321. Pinning these files aids reproduction. Runtime and hardware differences can still affect generation. Timeout is 12 seconds per request and the retry count is zero. A request marked in progress before interruption is recorded as interrupted on resume. Model readiness is checked before use. The maximum 128 pilot requests are accepted even when output is incorrect, missing, refused or malformed. No paid resources are used.

This is a feasibility sample with 16 paired variants in each of four strata. Under an illustrative per-item Brier difference standard deviation of 0.5, a simple (1.96 × 0.5 / √64) envelope is about 0.12 Brier units. This assumption does not establish power. The pilot is stopped at the registered number of planned requests regardless of effect; successful-responses coverage below 75% in complete eligible pairs makes the primary pilot comparison insufficient. No measured significance or confirmatory causal claim is planned.

## Outcomes and uncertainty

The primary estimand is the change in mean Brier loss (incorrect minus neutral) among tasks with valid answer-confidence pairs in both arms. The complete-pair estimand is conditional on observed format compliance so the two denominators and selection limitations are reported alongside the estimate. The point estimate weights observed pairs equally. Use a 4,000-draw percentile bootstrap with seed 61031, preserving the observed number of eligible pairs per task family. Percentile endpoints use linear interpolation at 2.5% and 97.5%. This estimates item variation conditional on the four chosen templates and does not justify generalization across task families or models.

Report per-arm full-task coverage, valid-answer accuracy, accuracy among confidence-bearing responses, mean reported confidence, calibration gap on the same eligible responses, Brier loss, log loss clipped to [0.000001, 0.999999], five equal-width reliability bins, error-positive AUROC with score 1 minus confidence, and inclusive tied-confidence risk-coverage thresholds. Give undefined metrics as missing. Secondary paired outcomes are neutral-to-incorrect changes in valid-answer accuracy and paired coverage, confidence and matched calibration gap, with their denominators and descriptive bootstrap intervals. Report cue-following and correct/wrong answer transitions among valid answer pairs. Secondary intervals are exploratory, with no multiplicity-adjusted significance claims. The mathematical random-answer baseline is expected accuracy 0.25 and Brier 0.1875 with constant confidence 0.25, and is separate from all genuine observations. No recalibration is fit.

The parser recognizes exactly one usable answer line and one usable probability line, permits case and surrounding ASCII whitespace, and distinguishes missing confidence, missing answer, malformed output, abstention, explicit refusals and truncation. Infrastructure failures, timeouts and interruptions remain in planned coverage. No repair of malformed output is performed after scoring. Confidence here is a verbal probability about the selected answer and does not measure internal uncertainty or subjective experience.
