# Independent review package

Independent human review is invited. No review has yet been recorded. Report issues against the exact tested release, cite the experiment ID, and attach a minimal fixture or source locator. An issue can propose a correction, a replication or a different interpretation. Protect credentials and restricted source documents.

| Track | Background | Verification task |
| --- | --- | --- |
| Mathematics | Probability, finite sums, linear algebra | Check the ECHO 2.0 moment constraints and two-sector ARTHA fixed point before attempting full replays. |
| Statistical design | Estimation, inference, multiple testing | Reproduce the SCIENTIA exact-tail discrepancy and assess original endpoints and correction policies. Inspect CONVERGENCE's unchanged inclusive intervals. |
| Economics | Market microstructure, accounting, national accounts | Verify one REFLEX fill and the ARTHA domestic/import orientation. Check how NEXUS keeps import and capex categories distinct. |
| Engineering and finance | Electrical units, cooling and finance | Recompute the ENERGIA idealized idle/load example, the debt annuity and the modeled year-five reserve draw. Review tariff and siting scope. |
| History | Historical measurements, rail systems and causal inference | Inspect Railway Board Statement 8, trace the aligned fiscal national values, inspect the RBI boundary note and assess treatment, outcome and comparison-unit readiness. |
| Software and accessibility | ESM, reproducible builds and browser testing | Verify archive byte identity, reproduce the issue, inspect keyboard order and error states, and check the static output's network requests. |

Use [the reproduction guide](../REPRODUCIBILITY.md) and [the evidence catalogue](https://neilmeher.github.io/synapse-research/library.html). Direct routine reviews to the [repository issue list](https://github.com/NeilMeher/synapse-research/issues). For a sensitive security issue use the repository's [security contact guidance](../SECURITY.md).

## Suggested report

1. Release tag, exact commit, browser or interpreter and OS.
2. Study ID, document, table, figure or code locator.
3. Command or steps, actual and expected result, and smallest reproducible case.
4. Scientific scope or assumption affected.
5. Severity and proposed correction.
6. Permission to share your reproduction evidence and any limits on attribution.
