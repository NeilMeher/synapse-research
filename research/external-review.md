# Independent review package

Independent human review is invited. No review has yet been recorded. Report issues against the exact tested release, cite the experiment ID, and attach a minimal fixture or source locator. An issue can propose a correction, a replication or a different interpretation. Protect credentials and restricted source documents.

## Suggested report

1. Release tag, exact commit, browser or interpreter and OS.
2. Study ID, document, table, figure or code locator.
3. Command or steps, actual and expected result, and smallest reproducible case.
4. Scientific scope or assumption affected.
5. Severity and proposed correction.
6. Permission to share your reproduction evidence and any limits on attribution.
