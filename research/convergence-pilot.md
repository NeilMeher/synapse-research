# CONVERGENCE exploratory pilot

Run 48 paired synthetic markets. Each has 15 traders, equiprobable positive and negative fundamental direction, marginal private reliability .65, and matching .30 correlation in shared-source and beta-binomial arms. The independent comparison has zero correlation. Every episode uses the same capital, agent ordering, cue count, fundamental and maker inventory across arms. Compare fixed size, probability-based sizing, and a style lottery. The latter and the calibrated rule have identical expected submitted size because the style lottery uses the same marginal high-size probability as cue agreement. Add equal and confidence-weighted neighbour messages only as ablations. Evaluate close midpoint error, submitted/executed units and mechanism logs. Independently reconstruct archived ledgers and route choice. Use the pilot to assess numerical and timing feasibility before freezing the confirmatory experiment.
