# CONVERGENCE confirmatory protocol

Freeze the protocol before execution. The 48-episode exploratory pilot checked 22 first-episode chain traces and 488 fills against the independent reference. It took 62 ms and the largest primary paired standard deviation was 69.53 ticks. Choose 1,200 held-out independent episodes with new seed 811201. The projected family-adjusted half-width for the noisier contrast is about 4.5 ticks. Task is the experimental unit and all arms use coupled random draws within it.

Each task uses 15 agents, binary truth, one ECHO report and one independent hint per agent. ECHO private report reliability is .65 and matched pairwise correlation is .30 in the shared-source and beta-binomial arms. A third independent condition sets correlation to zero. MIRAGE's probability formula uses report/hint agreement and marginal cue probabilities only. Hint accuracy is .70. An oracle for the current truth is not given to trading policies. The style mechanism independently chooses .95 or .65 with high probability .56, equal to the marginal probability of report/hint agreement. For either style or calibration retain one-unit requests below .75 and two above. Expected order size is 1.56 for both. The fixed size ablation uses one unit and has a different expected submitted volume. All actors have identical starting assets, cash, report counts, fundamental and market sequence across arms.

For the no-communication arms, submission direction always follows the ECHO report. Additional communication arms use equal or confidence-weighted neighbour messages in a fixed ring. The weights in those ablations are heuristic opinion weights. The stored confidence still refers to the original report. It is not interpreted as the posterior of the new action. Execution uses each arm's deterministic REFLEX inventory quotes, impact one or four ticks per unit, equal fee schedule, and no borrowed capital. The synthetic fundamental is 10,000 plus or minus 120 ticks. It is hidden from decision policies and used for downstream measurement.

## Outcomes

The two primary effects are the mean paired beta-minus-shared difference in absolute terminal midpoint pricing error under calibrated size and impact 4, and the difference between that effect and the analogous style-size effect. Use pairwise task moments and 97.5% normal intervals with Bonferroni familywise 95% coverage. Test both directions and report null or reversed findings. The 22 arm summaries and secondary pointwise intervals are descriptive. Monitor starting and ending balances, report accuracy and second moments, confidence Brier, order accuracy, requested/executed quantity, and signed net order flow. Keep the first episode for all arms.

Stop after 1,200 tasks or fail on resource cap, ledger mismatch, mismatched design moments, invalid configuration or failed deterministic verification. Archive no interim looks. The outcome is synthetic terminal pricing error in a miniature market. It does not measure financial contagion, real performance or general instability.
