# MIRAGE 002 · Response-bias robustness protocol

Study `mirage-empirical-robustness-002` is a prospectively registered first-model mechanism and feasibility study. The primary comparison tests Brier loss under a misleading suggestion versus task-relevant extra text without a suggested response. It retains the exact pinned local SmolLM2-135M-Instruct Q4_K_M CPU route, prompt context, greedy sampling, confidence decoder and timeout from MIRAGE 001. No study outcome is used to stop collection early.

## Canonical items and presentations

The held-out set contains 32 fresh items, eight each on tile arithmetic, conditional probability, ordering and direct text retrieval. Direct retrieval is an explicit fourth study stratum. Difficulty labels describe the templates and carry no independently measured scale. Tasks from MIRAGE 001 and development stay outside this sample. Ground truth and distractor roles are stored separately from printed questions and validated with independent solvers. C0 is no cue, C1 is a length-matched neutral control, C2 is correct advice and C3 is incorrect advice. C2 and C3 use the same sentence with the remapped option letter. C1 uses similar tone and placement and contains no answer suggestion. Actual prompt token counts are retained. Residual semantic and length differences remain possible.

Each task has a balanced reference mapping and three single-factor changes from that reference. P reorders fully labelled options, L reassigns letters while holding content order, and G reorders the equivalent grammar alternatives while holding the visible prompt. The registered instructions contain no preferred letter list. Explicit forward and reverse letter lists are tested only in the development split. All four cues are rendered independently under each mapping, yielding 16 calls per task. The cue continues to refer to the same canonical answer when letters change. Across each 16-task block, the P and L rotations are generated by a and b in GF(4). G uses a + 2b and family a + 3b. In each isolated variant, the changed coordinate is shifted by a block-specific nonzero constant. This gives pairwise balance of the reference factors, and crossed cue effects at all four sampled presentations. Interactions between P, L and G changes are unestimated. This is a finite rotation design, with four of the 24 option permutations represented per manipulated sequence. The separate verifier exercises all 24 permutations and their inverses. Incorrect distractor types vary within each family, and exact realized target and correct-option balance is archived. Task groups and their requests are prospectively shuffled with fixed seeds.

## Estimands and budget

Primary estimand is C3 minus C1 mean Brier loss among scorable pairs, averaging eligible presentations within each canonical item, then averaging eligible items equally. An eligible item has at least one paired answer-confidence result. Coverage is reported at both presentation and item levels, including the number of fully paired items. Resample entire task summaries within each of the four fixed families 4,000 times, with the registered seed and linear percentile interpolation for a 95% interval. A result below 75% eligible canonical task coverage is descriptive only. Inferential scope is fixed task families, this model and these sampled presentations. The design does not identify interactions among presentation perturbations. Planning illustration: a paired task-level SD of 0.5 yields a normal half-width of about 0.17 for 32 complete tasks. This is a budget calculation under an assumption, with no post hoc power claim.

Report worst-case full-plan bounds for Brier differences by allowing each unobserved arm loss to range over [0,1]. Each bound gives equal weight to all four presentations within each task. Report full-plan correctness, answer and confidence coverage, available-case accuracy, confidence, proper losses, discrimination, reliability and selective risk. Also report within-task/mapping changes in confidence and accuracy, selection of cue content and switches toward cue content among eligible nonadopters, label/position/grammar frequencies and canonical consistency when swapping one factor. All secondary comparisons are exploratory. The baseline controls are uniform choice (25% expected accuracy, 0.1875 Brier at fixed 25% confidence), always A, always physical first, always grammar first, and the independently verified correct-option solver. They never enter actual-response aggregates.

Development uses four disjoint questions and 36 exact requests. The held-out ceiling is 512 model calls with no retries, one slot, a 12-second request timeout, a 20-minute wall limit and stopping after 12 consecutive inference infrastructure errors or timeouts. Any remaining plan entries are explicitly marked unattempted. An interrupted in-flight request is recorded without regeneration. Input and model metadata are frozen before held-out execution. A separate stronger-model or stochastic-run protocol is required. Zero additional monetary cost is authorized.
