# ECHO 2.0 exploratory pilot

Run 500 independent paired task draws at n=15 and q=.68 with correlations 0, .25, .5, .75 and 1. Use seed 2711261. Inspect count-law normalization, moments, unanimous failure, majority, runtime and Monte Carlo dispersion. Keep analytic computation and Monte Carlo separate. Use common uniform arrays across all matched cells. Empirical majority scores a fair tie as one half, the conditional expected credit. This pilot is exploratory and may inform the choice of exact protocol and numerical check. No v1 input or archived output is replaced.
