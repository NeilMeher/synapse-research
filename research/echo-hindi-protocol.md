# ECHO English–Hindi economics protocol

**Retrospective archived model evidence (F).** The prediction publisher created all completions before this protocol. This registration freezes how SYNAPSE analyzes previously unopened Hindi outcomes. English outcomes come from the historical v1.4.0 archive. The estimand is an archive comparison across two configurations of task language, including translated prompts, stop strings and the language-dependent answer extraction rule.

## Outcome-blind selection

Start from the fixed 844 English economics items and the existing group assignments. Join the pinned English and Hindi benchmarks by both publisher question ID and original source plus original item ID. Confirm ordered option count, option uniqueness and keyed position. Each prediction row must match its canonical Hindi source and exact target prompt, including ordered choices. Match all fixed evaluation settings independently of responses. Use common checkpoints with identical recorded configuration settings except for the required Hindi task formatting. Publish the named mismatches. Olmo differs in context length, tensor parallelism and Transformers and enters only a labeled all-seven sensitivity.

Compare normalized signed numeric anchors in question and ordered options. An initial deterministic bilingual spot check found that source question 6992 lists statements that are absent from its Hindi question while answer choices still refer to them. Before any outcomes were opened, this triggered a prespecified-at-freeze screen for discrepancies in line-initial Roman-numbered statements across the entire cohort. Such rules can exclude innocuous formatting changes. A retained structural match plus a spot screen leaves residual translation error and does not certify every item. ## Estimation and controls

Primary outcome is the Hindi-minus-English paired difference in full-plan strict majority correctness. A strict majority requires at least four agreeing valid votes when six models report. Counts treat abstentions as zero correct. Use 4,000 paired bootstrap draws of source-question groups with fixed seed. Report wrong decisions, invalid labels, coverage, and conditional accuracy. Calculate within-language pairwise error phi and agreement on the same wrong choice, as well as same-checkpoint cross-language correctness dependence. The same questions and model set define both language arms. No claim about a causal effect of Hindi follows.

Compare fixed plurality, unanimity, majority followed by fallback to the historical calibration-selected Qwen, calibration-trained reliability weighting and one alternative agreement threshold. Their held-out differences and utilities are descriptive. On rows where strict majority issues an answer, report majority and Qwen correct counts using the same denominator. Fit separate calibration mappings from support for the plurality choice to its correctness, applying Laplace smoothing. Report held-out Brier against constant calibration and coverage. Agreement functions as an observable reliability input, with no reported individual confidence. Wrong-decision costs are stipulated at 0.25, 1 and 2, with correct payoff 1 and abstention payoff 0. Report implied model calls as well as zero new actual calls.

Transfer the original English accuracy-selected trio and quintet without reselection. Their cross-language comparisons are descriptive and use the same aligned held-out questions. Language and the language-dependent answer filter remain inseparable in this archive. Named checkpoints have no source weight revision hashes. A finite benchmark and already discussed English outcomes restrict the design. Future committee optimization needs new aligned held-out questions or an external benchmark.
