## Portable Vulkan development probe

The official b12823 Vulkan ZIP is 39,353,699 bytes with SHA-256 `57f0d96e28222142112cd47e49b6c3519b0df692caa837e2f7239456f1781110`. The executable matches the CPU package's binary hash, with a different verified Vulkan backend DLL. Its device probe found the GTX 1650 on the existing loader. The CUDA 12.4 package and its separately listed dependencies are substantially larger. CUDA compatibility was not established or exercised.

Four greedy SmolLM2 development calls repeated existing matched CPU requests after the main CPU model was stopped. All four GPU replies were scorable. Three of four raw strings and canonical answers agreed with CPU. The median per-request latency was **273 ms GPU versus 577 ms CPU**. The first GPU request took **4.394 s**, so pooled output tokens per request-second across all four were **13.1 GPU versus 27.3 CPU**. These rates include prompt evaluation and request overhead. Startup including checksum read took 3.801 s. Sampled device memory rose by 116 MiB over the idle snapshot, while the server working set peaked at about 340 MiB. The GPU memory value is system-wide telemetry at request boundaries. This is a four-request compatibility check. The GPU route needs a separately frozen Qwen capability run, current resource checks and authorization for the exact weights. It has not established Qwen performance. ## Literature and measurement scope

Wang et al. use repeated decoding and answer aggregation from chain-of-thought paths. MIRAGE 004 first tests whether increased diversity comes with improved correctness under a deliberately short, structured answer instrument. Zheng et al. and Pezeshkpour and Hruschka motivate the separate handling of printed letters and canonical answer content. Tian et al. contrast verbal confidence and token probabilities. llama.cpp b12823 can return top token log probabilities and has a documented post-sampling mode. The study did not collect these diagnostics, since a limited top-token list need not cover all grammar-constrained complete answer strings. No inference about internal accuracy probabilities is drawn from the available answer frequency or verbal confidence data.
