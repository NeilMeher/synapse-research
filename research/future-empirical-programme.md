# Proposed empirical research programme

The proposed first year shifts emphasis from new laboratories to independent review, replication and external validity. No live model benchmark or participant data collection was executed for this design document.

| Months | Priority | Evidence gate |
| --- | --- | --- |
| 1–2 | Independent mathematical and source review | Verify the ECHO 2.0 finite analysis, SCIENTIA discrepancy, ARTHA units and CHRONOS source scopes using the public review package. |
| 2–4 | Reproduce one benchmark on an outside machine | Record software versions, seeds, hashes and actual discrepancies. Publish replication whether or not outcomes agree. |
| 4–6 | Pilot MIRAGE-EMPIRICAL | Freeze a small answerable task set, disjoint calibration and held-out splits, confidence prompts, coverage and proper scores. Authorize actual API access and a budget before execution. Compare base and misleading cues under a paired design. |
| 6–8 | Design ECHO-EMPIRICAL | Compare cross-model error dependence and consensus under matched information. Record shared providers, prompts and model versions. Use task-level units and report calibration and missing responses. |
| 8–10 | Scope memory and scientific workflow tasks | Design MORPHEUS belief revision with traceable sources, NOESIS hypothesis proposals, and SCIENTIA verification traps. Require a documented rubric and separated judging assumptions. |
| 10–12 | Assess strategic and economic external validity | Test payoff-equivalent AXIOM prompts only after scoring validity and access are approved. Seek a lawful public empirical economic panel. Continue CHRONOS only if treatment and outcomes can be aligned. |

A registered model benchmark should store provider, exact model ID and availability date, prompt/configuration hashes, inference settings, tool access, versioned task sets, response logs where permitted, and failures including refusals and nonresponses. The comparison needs declared ground truth and event-level uncertainty suitable for the observation units. Synthetic controls and actual model responses receive distinct evidence labels. No consumer UI automation or paid API use is authorized by this plan.

For human studies, obtain appropriate ethics and informed-consent review in a separate protocol. Minimize personal data and set access, retention and deletion terms before recruitment. A behavioural experiment can measure calibration, memory or decisions. Subjective consciousness remains outside direct behavioural verification. ## Candidate future peer-influence design

After the model/measurement gate, obtain an initial independent canonical response before any peer message. On a fresh task set, randomly assign a matched neutral statement or one inaccurate peer response with confidence wording varied in a second independent factor. Prespecify switching from a correct canonical answer as the main conditional outcome and report the denominator, full-plan correctness and abstention separately. Counterbalance answer labels and use correct-peer and length controls if resources permit. The advice can be an explicit scripted treatment. It should never be presented in reporting as a genuine independent model vote. [MIRAGE protocol](mirage-robustness-protocol.md)
