Available RAM was about 0.95 GiB at inspection. The 4 GiB discrete GPU had about 3.30 GiB free and was left idle by inference. Python 3.14.0 and Node 24.12.0 were present. The first local smoke run completed 16 requests in 22.7 seconds. Ten responses had an invalid format and six were truncated. After simplifying the prompt and constraining the response format, a separate development run completed 16 requests in 21.4 seconds, with 13 scorable and three abstentions. Median latency was 1.19 seconds and largest reported prompt-plus-completion was 157 tokens. For 128 planned pilot completions this suggested roughly three minutes. The pinned CPU runtime and weights required 131 MB download and less than 250 MB temporary storage including extracted runtime. The estimate before collection was below 0.5 GiB working memory with a 512-token context. The run budget is two CPU threads and zero additional monetary cost. Development responses are separate local controls that do not enter pilot aggregates. Model weights and runtime are obtained from their publishers through the verified links.

The upstream 135M card describes the small model's limited factual and logical performance. GGUF quantization and runtime decoding settings define the evaluated variant.
